计算机网络：TCP/IP 协议栈

一、TCP/IP 分层模型

TCP/IP 协议栈通常分为四层：
1. 应用层（Application Layer）：HTTP、FTP、SMTP、DNS 等
2. 传输层（Transport Layer）：TCP、UDP
3. 网络层（Internet Layer）：IP、ICMP、ARP
4. 网络接口层（Link Layer）：以太网、Wi-Fi、PPP

二、IP 地址与子网划分

IPv4 地址长度为 32 位，通常用点分十进制表示，如 192.168.1.1。
IP 地址分为网络号和主机号两部分，通过子网掩码区分。

常见私有地址范围：
- A 类：10.0.0.0 ~ 10.255.255.255
- B 类：172.16.0.0 ~ 172.31.255.255
- C 类：192.168.0.0 ~ 192.168.255.255

CIDR（无类别域间路由）使用“/n”表示前缀长度，如 192.168.1.0/24。

三、TCP 三次握手

TCP 建立连接需要三次握手：
1. 客户端发送 SYN=1, seq=x
2. 服务器回复 SYN=1, ACK=1, seq=y, ack=x+1
3. 客户端发送 ACK=1, seq=x+1, ack=y+1

三次握手的目的是同步双方初始序列号，并确认收发能力正常。

四、TCP 与 UDP 对比

- TCP：面向连接、可靠传输、流量控制、拥塞控制，适用于 HTTP、FTP、邮件等
- UDP：无连接、不可靠、低延迟，适用于视频直播、DNS、在线游戏等

五、ARP 协议

ARP（地址解析协议）用于根据 IP 地址获取对应的 MAC 地址。
工作过程：
1. 主机广播 ARP 请求，询问“谁是 192.168.1.1？”
2. 目标主机单播回复自己的 MAC 地址
3. 请求方缓存 ARP 表项
